BMI Calculator
Кратко описание

Малък статичен уеб проект за изчисляване на Body Mass Index (BMI).
Вход: тегло (kg) и ръст (cm). Изход: стойност на BMI и текстова оценка (поднормено/нормално/наднормено/затлъстяване).
Файлова структура

index.html — основна HTML страница
style.css — стилове
script.js — логика за изчисление и показване на резултата
